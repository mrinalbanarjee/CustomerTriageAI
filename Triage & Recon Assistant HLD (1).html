Triage & Recon Assistant HLD

Triage & Recon Assistant high-level design

Step by step

Letters mark the two ways into triage, and numbers match the diagram. Lines marked Future are planned.

  1. A

    Background service Current

    It pulls Splunk alerts and the MongoDB records of account sync issues, each with an account number and ECN, and triages every new issue.

  2. B

    Triage chatbot Current

    A user asks about an issue in the Triage nav of the web UI. The chatbot first looks for an existing triage record and answers from it. If the issue is new, it runs the triage and saves the result.

  3. 1

    Classify Current

    The LLM matches the issue to an L2 and the L1 component at fault, using a ChromaDB vector search. Today that is Auto Loan Admin › Loan Boarding.

    Future: more L1s such as Statement, plus the Customer Communication and Recovery L2s.

  4. 2

    Triage by runbook Current

    It follows that component’s runbook, kept in Confluence or as a prompt, and queries the audit tables at each step.

    Future: Splunk log searches with queries the LLM writes.

  5. 3

    Build remediation actions Current

    It saves the triage record and its remediation actions to the one MongoDB collection that both ways in share. An action can be a Mongo reprocess script, an Alfa update script in Python, a ServiceNow incident, a Jira defect or an Alfa case.

  6. 4

    Test in a lower environment Current

    On the Triage & Recon Dashboard, a separate UI component, a person opens a record, picks an action and an environment such as UAT, and submits. The test API queues a run, the test runner applies the action there and checks the result, and the dashboard shows the outcome. Today it tests Mongo reprocess scripts and Alfa update scripts.

    Future: testers for ServiceNow incidents, Jira defects and Alfa cases.

  7. 5

    Deploy to prod Future

    After a test passes, the dashboard plans the production deploy. The IDP portal raises a ServiceNow change with the gameplan and test script attached, and the fix goes to production under that change.
